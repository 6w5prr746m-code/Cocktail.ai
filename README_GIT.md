# Avant de committer : vérification des identifiants placeholder

Ce projet contient encore des identifiants CloudKit/App Group en
placeholder (`iCloud.com.peoplespheres.cocktailapp`,
`group.com.peoplespheres.cocktailapp`) — ce ne sont pas des secrets, ce
sont des chaînes d'exemple non fonctionnelles, sans risque à committer en
l'état. Remplacez-les par vos vrais identifiants une fois le compte
Apple Developer configuré (voir Guide_Montage_Xcode_CocktailApp.md),
de préférence dans une branche ou un commit ultérieur si vous voulez
garder l'historique propre.
